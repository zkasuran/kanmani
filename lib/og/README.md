# The link card

`app/og.png/route.tsx` draws the card shared links show, from `base.png` plus the live figures.

- `base.png` is the 2026-09-25 card (`scripts/build-media.py`) with its typed figures line removed.
- `DejaVuSansMono.ttf` is the mono face the original card used. DejaVu fonts are free to use and
  redistribute (Bitstream Vera licence plus public-domain changes), https://dejavu-fonts.github.io/License.html
