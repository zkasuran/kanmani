# 35. The machine surfaces

Fourteen GET surfaces are served for software rather than for a browser. Twelve are machine endpoints
under `app/*/route.ts` outside `app/api`, plus the `og.png` image route and one static file in
`public/`. This is the catalogue, with the four that no other doc covers described in full.

| path | content-type | cache | what it is |
|---|---|---|---|
| `/openapi.json` | `application/json` | `max-age=300` | OpenAPI 3.1 for the public API. Described below |
| `/skill.md` | `text/markdown` | `max-age=300` | an agentskills.io SKILL.md of the build guide. Described below |
| `/build/AGENTS.md` | `text/markdown` | `max-age=300` | a drop-in `AGENTS.md` for a repo that builds an agent. Described below |
| `/.well-known/agent-card.json` | `application/json` | `max-age=300` | our A2A agent card, for discovery. Described below |
| `/mcp` | `application/json` | none | the MCP server. See [33-MCP](33-MCP.md) |
| `/llms.txt` | `text/plain` | `no-store` | the whole site as plain text with live numbers |
| `/schema.json` | `application/json` | `no-store` | hand-written JSON Schema for the envelope, the verdict and the record states |
| `/agents.md` | `text/markdown` | `no-store` | the safe-access contract, addressed to software |
| `/feed.json` | `application/json` | `no-store` | the whole checked population plus its distribution. See [10-API](10-API.md) |
| `/sitemap.xml` | `application/xml` | `no-store` | capped at 200 operator clusters and 500 claims, with the cap stated in an XML comment inside the file |
| `/.well-known/agent-registration.json` | `application/json` | `no-store` | our own ERC-8004 record |
| `/embed.js` | `application/javascript` | `max-age=300` | the embeddable verdict badge. See [24-KIT-LICENCE](24-KIT-LICENCE.md) |
| `/og.png` | `image/png` | `max-age=900` | the share-card image, with its figures drawn from live data rather than typed in |
| `/self-audit.json` | `application/json` | static file | every agent Kanmani operates, checked by Kanmani. See [31-SELF-AUDIT](31-SELF-AUDIT.md) |

Ten of them set `access-control-allow-origin: *`, so a browser can read them cross-origin. Four do
not: `/mcp`, `/.well-known/agent-registration.json`, `/og.png` and `/self-audit.json`. The absence is
stated rather than smoothed over, because a browser client that assumes the header is everywhere hits
a preflight it cannot explain. Server-side clients are unaffected either way.

The four `max-age=300` markdown and JSON generators are rendered per request rather than at build
time. `SITE` comes from the server environment and a build-time render baked the local fallback URL
into every link of the published file.

## `/openapi.json`

OpenAPI 3.1, generated by `lib/openapi.ts`. It exists because that is the format agent frameworks
(OpenAI Agents SDK, LangChain, CrewAI, Semantic Kernel, Dify), GPT Actions and no-code tools (n8n,
Zapier, Make, Pipedream) import to turn an HTTP API into callable tools.

Eight operations, each with an `operationId` written as a tool name a model can pick:

| path | operationId | tag |
|---|---|---|
| `POST /api/registration/check` | `check_registration` | build |
| `POST /api/evidence/check` | `check_evidence` | build |
| `GET /api/agent/{id}` | `get_agent` | read |
| `GET /api/account/{address}` | `get_account` | read |
| `GET /api/claims` | `list_claims` | read |
| `GET /api/sla/{agentId}` | `get_claim_truth_rate` | read |
| `POST /api/verify` | `verify_hosted_document` | paid |
| `GET /api/service/{slug}` | `get_agent_service` | paid |

`security` is an empty array on purpose. Every endpoint is public and the paid ones carry x402 in the
request rather than a key, so there is no security scheme to declare. A spec that invented a bearer
scheme would send every importing tool looking for a key that does not exist.

`lib/openapi.test.ts` parses this spec and asserts every path maps to a route file under `app/`, so a
route cannot be renamed or removed without the test failing. That is the guard against the usual
failure of a hand-maintained spec, which is quietly describing an endpoint that is gone.

The shared envelope and the RFC 9457 problem shape are both declared, along with `RegistrationInput`,
`RegistrationReport` and `EvidenceReport`. `canSend` is documented as three-valued and the
description states plainly that `unknown` must not be treated as `false`.

```bash
curl -sS https://kanmani.xyz/openapi.json | jq '.paths | keys'
```

## `/skill.md`

The build guide with agentskills.io frontmatter on top, from `skillMd()` in `lib/build-guide.ts`.
Install it by saving it where your tool keeps skills:

```bash
curl -sS https://kanmani.xyz/skill.md > ~/.claude/skills/kanmani/SKILL.md
```

The frontmatter carries `name: kanmani-erc8004-agent`, a one-paragraph `description` that says when to
use it, `license: MIT` and a `metadata` block with the homepage and version. The `description` is
emitted as a JSON string, which is valid YAML. Unquoted, its `": "` made strict YAML parsers reject
the whole file, so a skill loader silently skipped it.

The body is the five-step build guide: write the document, check the draft, send the transaction, test
the evidence, then optionally take payments over x402. It is also published as the MCP resource
`build-guide`, so a model that has the MCP server connected can read the guide without a second fetch.

**This is an export, not an import.** Kanmani does not read an operator's `SKILL.md`. A skill.md
import is listed as missing in [14-GAPS](14-GAPS.md), which is a different feature.

## `/build/AGENTS.md`

The same guide shaped as an `AGENTS.md` for the root of a repo, from `agentsMdDropIn()`. Append it and
every coding agent working in that repo reads the rules:

```bash
curl -sS https://kanmani.xyz/build/AGENTS.md >> AGENTS.md
```

It names `/skill.md` as its own source of truth at the top, so a stale copy in a repo can be refreshed
from one line rather than diffed by hand.

## `/.well-known/agent-card.json`

Our A2A agent card, from `agentCard()` in `lib/openapi.ts`. For discovery only.

**The card does not claim an A2A endpoint, because we do not speak A2A's message protocol.** Its
`supportedInterfaces` are the two that exist:

```json
"supportedInterfaces": [
  { "url": "https://kanmani.xyz/mcp", "protocolBinding": "MCP-STREAMABLE-HTTP", "protocolVersion": "2025-06-18" },
  { "url": "https://kanmani.xyz/openapi.json", "protocolBinding": "HTTP+OPENAPI", "protocolVersion": "3.1.0" }
]
```

A card listing a JSON-RPC URL we do not serve would send a client to a 404 that looks like an outage.
`capabilities` reports `streaming: false` and `pushNotifications: false` for the same reason.
`securitySchemes` and `securityRequirements` are empty, matching the OpenAPI spec.

Three skills are declared with examples: `check-registration`, `check-evidence` and `read-verdicts`.

The twelve hireable agents each publish their own A2A card at
`/api/service/<slug>/agent-card.json`, which is the card their ERC-8004 registration points at. See
[30-AGENTS](30-AGENTS.md).
