# DATA-SOURCES

Third-party inputs that travel with what this site publishes, each with the clause that permits the
use. Code dependencies are in `NOTICE`; this file covers the non-code inputs.

## Fonts

Three faces are pulled by `next/font/google` in `app/layout.tsx` and self-hosted into the build
output, so they are served from our own origin to every visitor rather than linked from Google at
runtime. That is a deliberate choice: the Content-Security-Policy is `style-src 'self'` and
`font-src 'self' data:`, so a `fonts.googleapis.com` stylesheet would be refused by the browser and
every face would silently fall back.

Because the faces are embedded in the published artifact, the licence travels with it. The OFL
requires its copyright and licence notice to ship alongside the font. Self-hosting through
`next/font` does not carry that notice by itself, so this file is what carries it.

All three are under the SIL Open Font License, Version 1.1. Each copyright line below was read from
that face's own `OFL.txt` in the upstream `google/fonts` repository.

| Face | Used for | Copyright line from its own OFL.txt |
|---|---|---|
| Inter | body text, `--font-inter` | Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter) |
| JetBrains Mono | hashes, addresses and commands, `--font-jetbrains` | Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) |
| Space Grotesk | headings, `--font-space-grotesk` | Copyright 2020 The Space Grotesk Project Authors (https://github.com/floriankarsten/space-grotesk) |

Each `OFL.txt` states:

> This Font Software is licensed under the SIL Open Font License, Version 1.1.

and the operative grant reads:

<!-- voice-gate:off  the OFL grant below is quoted byte for byte and must not be reworded -->
> Permission is hereby granted, free of charge, to any person obtaining a copy of the Font Software,
> to use, study, copy, merge, embed, modify, redistribute, and sell modified and unmodified copies of
> the Font Software, subject to the following conditions:

The conditions that bear on how the faces are used here: the copyright notice and licence must travel
with the Font Software, which is what the table above does; the faces must not be sold on their own,
which they are not; and a modified version must not use the reserved font names. The faces are
embedded unmodified, so no renaming obligation arises.

## Images and generated assets

`public/banner.png`, `public/apple-icon.png`, `public/brand/`, `public/readme/`, `app/icon.svg` and
the inline mark in `components/logo.tsx` are this project's own brand work. They are generated by
`scripts/build-assets.py`, `scripts/build-media.py` and `scripts/build-readme-art.py` from geometry
in this repository. No third-party image is bundled, so no image carries an outside clause.

`public/self-audit.json` is output written by `scripts/self-audit.mjs` against our own deployment.

## On-chain and API data

The measurements this site publishes are read from public sources rather than licensed datasets:

- Monad mainnet (chain 143) and Monad testnet (chain 10143), read over JSON-RPC. Public chain state.
- The ERC-8004 Identity, Reputation and Validation registries on chain 143, read through our own
  indexer. Public contract state.
- Evidence documents at the URIs agents themselves registered, fetched through the SSRF guard in
  `verifier/src/net/guard.ts` and capped at 64 KiB.

Facts read from a public chain are not anyone's copyrighted material, so none of this carries a
licence condition. Where a third-party HTTP API is called with a key, the key is read from the
environment and the response is used as a live reading rather than stored as a dataset.
